Report errors, collect feedback and open tickets from your own app with one key and a few lines of code.

Manage keys

Start in three steps

  1. Make a key. Keys belong to one product. {% if can_manage_keys %}Create one on the product page.{% else %}Ask an owner, admin or developer for one.{% endif %} It is shown once.
  2. Send a request. Put the key in an Authorization: Bearer header and POST JSON to {{ base_url }}api/v1/errors/capture/.
  3. Look in Errors. It appears within a second, grouped with matching errors.
Base URL
{{ base_url }}api/v1/
Authentication
Authorization: Bearer YOUR_API_KEY
Format
JSON in, JSON out
Limit
600 requests a minute per key

Use https in production. Never put a key in front-end code that anyone can read. Send from your server, or use a key you are happy to rotate.
