{% load icon_tags %} {% comment %} Punch control — the one thing an employee opens this page to do. Rendered from two places, `MyAttendanceView` on a page load and `AttendancePunchView` on an htmx punch, both through `_punch_context`, so the two can never disagree about what state the day is in. After a punch the server re-renders this partial, so the DOM is never stale; the Alpine `x-text` only ticks the elapsed counter locally between requests. Three things it has to get right: * **Show when you checked in, not just how long you have been here.** The old panel said "On the clock since" and then printed a *duration*, so the one number an employee wanted — the time — was nowhere on the screen. * **Say "late" when it happens.** A late punch costs Rs 50 / Rs 100 / half a day, and this panel used to not mention it at all, so the first notice was a payslip weeks later. The band comes from `late_penalty_for`, the same call the payslip makes, so the two cannot quote different numbers. * **Repeat a forgotten check-out from an earlier day.** It is the reason the hours are capped, and hiding it here is how it went unnoticed for weeks. The three states are `is_complete` (day done), `is_open_today` (on the clock) and neither (not in yet). `is_open` alone cannot pick between the last two — see `apps/attendance/models.py`. {% endcomment %}
