The question this dialog answers is "what changed in the version I'm looking at?", so it opens on the newest release alone -- not the whole file. The full file is 56 bullets across three blocks, two of which are also tagged "Unreleased" with the same date, so showing everything at once reads as one undifferentiated wall. Older blocks are one click away, and the type chips narrow the current one to "just the fixes" without scrolling past 24 items. {% endcomment %}
