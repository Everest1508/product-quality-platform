{% comment %} One choice control for the whole app, in the same idiom as the leave icon picker: a native
holding radios (or checkboxes, when multiple). Why
and not a hand-rolled listbox: * Radios inside a collapsed
are still submitted, so the value posts with the form when JavaScript is off. A
-and- menu does not. * Radios fire a native `change` event, so every `hx-trigger="change"` form keeps filtering without being touched. * Arrow keys, form semantics and the mobile picker come from the platform. The only thing
cannot do on its own is relabel the closed button after a choice is made, so the trigger carries `x-data="dd"` and Alpine syncs the text from the checked input. Server-rendered `closed_label` is the no-JS fallback and is already correct on first paint. {% endcomment %}
